# 찜꽁 Helper 개인정보처리방침

시행일: 2026-03-01

찜꽁 Helper(이하 "확장 프로그램")는 찜꽁 게스트 페이지의 회의실 예약 보조 기능을 제공하기 위해 필요한 최소한의 정보만 처리합니다.

## 1. 수집·처리하는 정보
- 예약 화면 표시 및 자동 입력을 위해 찜꽁 게스트 페이지에서 제공되는 예약 관련 정보(날짜, 시간, 공간명, 예약 상태)를 일시적으로 처리합니다.
- 내 예약 조회 기능 제공을 위해 로그인 상태에서 예약 API 응답 데이터(예약 시간, 공간, 사용 목적, 예약자명)를 일시적으로 처리합니다.
- API 호출 시 인증을 위해 페이지에 존재하는 로그인 토큰 정보를 읽어 요청 헤더에 사용할 수 있습니다.
- "이 예약 공유" 버튼 클릭 시 공유 문구를 클립보드에 복사합니다(사용자 명시 동작 시에만 실행).

## 2. 이용 목적
- 층별 타임테이블 표시
- 빈 시간 자동 선택 및 예약 폼 자동 입력
- 내 예약 표시 및 예약 공유 텍스트 생성

## 3. 보관 및 파기
- 확장 프로그램은 위 정보를 개발자 서버로 전송하거나 별도 영구 저장소에 저장하지 않습니다.
- 데이터는 기능 수행 중 메모리에서 일시적으로만 사용되며, 페이지 종료/새로고침/확장 재시작 시 사라질 수 있습니다.

## 4. 제3자 제공 및 외부 전송
- 본 확장 프로그램은 개발자 소유의 외부 서버로 데이터를 전송하지 않습니다.
- 기능 수행에 필요한 경우, 사용자가 접속한 찜꽁 서비스의 공식 API(`k8s.zzimkkong.com`)로만 요청을 보냅니다.

## 5. 이용자 권리
- 사용자는 언제든지 확장 프로그램을 비활성화 또는 삭제하여 정보 처리를 중단할 수 있습니다.
- 공유 기능은 사용자가 버튼을 클릭한 경우에만 동작합니다.
